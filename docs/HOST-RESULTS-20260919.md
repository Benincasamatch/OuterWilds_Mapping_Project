- **横向桌面拖动：通过真实人工操作验证。**
- **桌面滚轮：未收到事件，未通过原硬性要求。** 已提供屏幕缩放按钮作为备用，但按钮不能替代该要求的验收，且仍需真实桌面点击确认。

## 测试工具修正

- CPU 差值必须显式 double，避免 PowerShell Math.Max 的整数重载把小数舍入为零。初次试跑已作废。
- GPU Counter 会因不相关进程退出给整个查询报错；改为逐个检查目标进程计数 Status，仍保留缺失标记，不把缺失当成零。
- 采样循环原先在 GPU 查询耗时后结束，CPU 实际覆盖可能略少于目标；改为根据最后 CPU 采样时间判断停止。这不追溯修改已取得的 599.17s 数据。
- 汇总要求连续心跳、绘制计数递增、同一会话、稳定尺寸、足够采样时间。重启或停顿判为证据不完整。
